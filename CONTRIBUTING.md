# Contributing

## Commit history
The UTS brief requires meaningful commit history from every member. Separate branches are optional; meaningful individual commits are the key requirement.

## Commit style
Use task commit messages from the worksheet.

## Before commit
```bash
pytest
python -m compileall .
```

## Review
Check functionality, tests, secrets, README, report evidence, and demo readiness.

## AI disclosure
Record AI-assisted sections in the report appendix and ensure each member understands the code.
